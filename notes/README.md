# Analyst notes

One file per weekly run: `notes/YYYY-MM-DD.md` (the snapshot's as-of date). Use the report's section names as
`##` headings — `Executive Summary`, `Liquidity Update`, `Central Banks`, `Consumer and Employment`, `Economic Cycle`,
`Financial Markets`, `Investment Implications`, `Forward Outlook`. Each note appears under its section, labelled
"Analyst interpretation". Keep each under ~120 words. See RUNBOOK.md for rules and for scenario adjustments.
